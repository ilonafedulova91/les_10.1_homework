# Banking Operations Widget

## Описание проекта
Проект представляет собой бэкенд‑часть виджета для личного кабинета клиента банка. Виджет отображает несколько последних *успешных банковских операций* клиента.

В рамках проекта реализованы функции для:

- маскировки номеров банковских карт и счетов

- форматирования дат

- фильтрации и сортировки операций

Проект развивается пошагово в рамках домашних заданий курса.

## Цель проекта
Подготовка и обработка банковских данных для безопасного и удобного отображения в пользовательском интерфейсе:

- защита чувствительных данных (карты, счета)

- удобная работа с датами

- фильтрация и сортировка операций

## Установка и настройка
### 1. Клонирование репозитория
git clone <URL_репозитория>


### 2. Установка зависимостей
Проект использует `Poetry` для управления зависимостями.

Требования

- Python 3.10 или выше

- Poetry 1.5 или выше

*Установка зависимостей проекта*

В корне проекта выполните команду:

`poetry install`

Эта команда:

- создаст виртуальное окружение

- установит все зависимости из файлов pyproject.toml и poetry.lock

Для установки дополнительных инструментов выполнитe:

`poetry install --with lint`

В группу lint входят:

- `flake8` — проверка стиля

- `black` — форматирование

- `isort` — сортировка импортов

- `mypy` — проверка типов

Запуск:

`poetry run flake8 src`

`poetry run black src`

`poetry run isort src`

`poetry run mypy src`

## Реализованные модули и функции

### masks

`get_mask_card_number(card_number: str) -> str`

Маскирует номер банковской карты.

Пример:

get_mask_card_number("7000792289606361")

7000 79** **** 6361

`get_mask_account(account_number: str) -> str`

Маскирует номер банковского счета.

Пример:

get_mask_account("73654108430135874305")

**4305

### widget

`mask_account_card(data: str) -> str`

Определяет тип данных (карта или счёт) и возвращает замаскированный номер.

Примеры:

mask_account_card("Visa Platinum 7000792289606361")

Visa Platinum 7000 79** **** 6361

mask_account_card("Счет 73654108430135874305")

Счет **4305

`get_date(date_str: str) -> str`

Преобразует дату из ISO‑формата в формат ДД.ММ.ГГГГ.

Пример:

get_date("2024-03-11T02:26:18.671407")

11.03.2024

### processing

`filter_by_state(data: list[dict], state: str = 'EXECUTED') -> list[dict]`

Фильтрует операции по статусу.

Пример:

filter_by_state(operations)

filter_by_state(operations, 'CANCELED')

`sort_by_date(data: list[dict], reverse: bool = True) -> list[dict]`

Сортирует операции по дате.

Пример:

sort_by_date(operations)

sort_by_date(operations, reverse=False)

## Тестирование

В проекте реализовано модульное тестирование с использованием библиотеки **pytest**.  
Все тесты расположены в директории `tests/` и покрывают ключевую функциональность проекта.

### Структура тестов

#### `test_masks.py`
Проверяется корректность маскирования номеров карт и счетов:

- `get_mask_card_number`:
  - корректное маскирование номеров карт;
  - поддержка строк с пробелами;
  - обработка некорректных значений (пустая строка, ноль, неверная длина).
- `get_mask_account`:
  - корректное маскирование номеров счетов;
  - обработка строковых и числовых значений;
  - выброс `ValueError` при некорректных данных.

Используется параметризация тестов для проверки разных входных данных.

#### `test_widget.py`
Тестируются функции форматирования данных для отображения:

- `mask_account_card`:
  - корректное определение типа (карта / счёт);
  - маскирование номеров с сохранением названия карты или счёта;
  - обработка ошибок типов и некорректных входных данных.
- `get_date`:
  - преобразование даты из формата ISO (`YYYY-MM-DDTHH:MM:SS`) в формат `DD.MM.YYYY`;
  - обработка пустых строк и некорректных форматов дат.

#### `test_processing.py`
Проверяется логика обработки списков операций:

- `filter_by_state`:
  - фильтрация по статусу (`EXECUTED`, `CANCELED`);
  - работа при отсутствии совпадений;
  - обработка ошибок при некорректных входных данных.
- `sort_by_date`:
  - сортировка по дате по убыванию и возрастанию;
  - корректная работа при одинаковых датах;
  - проверка ошибок при пустом списке и некорректных значениях дат.

Для подготовки тестовых данных используются фикстуры `pytest`.

### Запуск тестов

Для запуска всех тестов выполните команду из корня проекта:

`pytest`
